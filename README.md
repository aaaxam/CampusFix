🖥️ CampusFix 校园电脑维护预约系统

一、项目简介

CampusFix 是一个面向校园电脑协会的电脑维护预约系统，用于规范学生提交维修需求、工作人员接单处理、完成服务以及学生评价的流程。

基础业务流程为：
用户发单 > 工作人员接单 > 工作人员完成服务 > 用户评价

本项目不涉及线上支付，所有维修服务均由工作人员线下完成。

二、主要功能

1. 学生注册和登录
2. 电脑维修预约
3. 故障类型和优先级选择
4. 维修订单管理
5. 工作人员接单和完成维修
6. 学生维修评价
7. 订单状态流转
8. 学生和工作人员权限区分

三、拓展功能

1. 订单编号
自动生成订单编号，例如 CF202610070001，方便识别和管理订单。

2. 订单时间线
记录订单提交、工作人员接单、完成维修、学生评价等时间，使订单流程更加直观。

3. 订单取消
工作人员接单前，学生可以主动取消维修预约。

4. 订单优先级
支持普通、紧急、非常紧急三种优先级。

5. 数据看板
工作人员可以查看订单数量、完成率、平均评分、故障类型和优先级等数据。

6. 账号数据隔离
学生只能查看自己的维修订单，不能查看工作人员端页面，工作人员可以查看全部订单。

7. 修改密码
学生可以修改自己的登录密码。

五、技术实现

使用 HTML、CSS、JavaScript 开发。

使用 LocalStorage 保存用户和订单数据。

使用 VS Code 进行开发，生成式ai辅助，通过 Live Server 进行本地运行。

项目目前不使用后端服务器和数据库。
